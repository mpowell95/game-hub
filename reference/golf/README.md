# Golf reference frames

Club tile art lifted from the reference game's own screen recordings, at full
device resolution, for redrawing against.

| file | clip | frame | tile read |
|---|---|---|---|
| `club-driver.png` | Tee shot (hole 2, shot 1) | 287 | driver |
| `club-wood.png`   | Shot 2, bounce into sand  | 690 | 3 wood |
| `club-iron.png`   | Bunker shot, shot 3       | 700 | 7 iron |
| `club-wedge.png`  | Bunker shot, shot 3       | 60  | s. wedge |
| `club-putter.png` | Putt to finish            | 270 | putter |

All are a 300x195 crop at (72, 2205) of a 1206x2622 frame, so the club sits in
the same place in each and they can be compared directly. One art pixel is
about 6 device pixels; view them with nearest-neighbour scaling, not smoothing.

Traced versions of these, and what the trace corrected, are in the session
notes for golf's club tile work - see `golf/CLAUDE.md`.
