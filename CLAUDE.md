# Game Hub

The app (everything a phone needs) lives in this public repository. The project's instructions, server code, tools, tests and
notes live in the PRIVATE repository **mpowell95/game-hub-server**. Before any work:

1. Attach both repositories to the session (`mpowell95/game-hub` and `mpowell95/game-hub-server`), cloned side by side.
2. Run `sh ../game-hub-server/setup.sh` from this folder. It links the tools, notes and server code into this folder.
3. Read and follow `../game-hub-server/CLAUDE.md`. It is the full set of rules for this project.

Never copy anything from the private repository into this one.
